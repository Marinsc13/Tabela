🏀 Tabela NBA 21/22

Projeto simples de uma tabela em HTML exibindo a classificação de três times da NBA na temporada 2021/2022.

🔧 Tecnologias

HTML5

CSS

📋 Funcionalidades

Tabela com:

Posição

Nome do time

Número de vitórias

Número de jogos (com uso de rowspan)

Estilização com cores para destacar informações importantes

🎨 Estilo

Destaques em azul (cornflowerblue) para facilitar a leitura

caption com borda preta

Layout simples e fácil de entender
